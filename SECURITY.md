# Security Policy

## Reporting a Vulnerability

**VOIRIA SASU** takes the security of Docurama and its users seriously.

If you discover a security vulnerability, please report it responsibly:

- **Email:** [security@docurama.eu](mailto:security@docurama.eu)
- **Response SLA:** Acknowledgement within 48 hours, initial assessment within 5 business days.

See the full security policy in the [Docurama Cloud repository](https://github.com/StalFe-Cloud/docurama/blob/main/SECURITY.md).
